## Project Objective

The goal of this assignment was **not** to create a pixel-perfect copy of apple.com, but to practice building a real-world responsive layout using modern CSS techniques such as **Flexbox**, **CSS Grid**, **Positioning**, **Media Queries**, and **Transitions**.

## Why I Used Flexbox and Grid

### Flexbox

I used **Flexbox** for components that require **one-dimensional alignment** (row or column), such as:

* Navigation bar
* Hero section button groups
* Footer alignment

Flexbox made it easy to center content and distribute space evenly between items.

### CSS Grid

I used **CSS Grid** for the **product feature section** because it is designed for **two-dimensional layouts** (rows and columns). Grid allowed me to create a clean **2-column desktop layout** that automatically changes to a **1-column mobile layout** using media queries.

---

## Responsive Design

The layout adapts to different screen sizes using media queries:

* **Desktop:** Multi-column feature grid and horizontal navigation.
* **Tablet:** Adjusted spacing and typography.
* **Mobile:** Single-column feature grid and stacked navigation layout.
